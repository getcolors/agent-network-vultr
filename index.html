agent-network-vultr

Desired state for one minimal NetBird Agent Network demo: Traefik, the combined netbird-server, the dashboard in agent-network view, the private reverse proxy — and an isolated agent whose only path to an LLM is the keyless endpoint over its WireGuard tunnel.

The isolation is the demo. The agent container holds no API key and has no internet route — an internal Docker network doubled by DOCKER-USER firewall rules. Its requests reach <label>.agent-network.bigconfig.online over the tunnel, carry its peer identity, pass a policy with a model allowlist and per-day budget caps, and land attributed in the access log. The Anthropic key lives server-side in NetBird's encrypted store.

Endpoints

https://agent-network.bigconfig.online          dashboard, API, gRPC, relay, embedded IdP
https://<label>.agent-network.bigconfig.online  the keyless endpoint — tunnel-only
agent-network-agent                             the isolated agent container

Use

direnv allow               # once, after cloning
./green build              # render .colors/agent-network-vultr/
./green create --dry-run   # walk the workflow, no side effects
./green create             # converge
Fake-key mode. This deployment runs with a deliberately fake Anthropic key: acceptance expects Anthropic's own 401 relayed through the proxy, proving isolation, tunnel, policy and key injection with nothing billable. A real key in .envrc.private and a re-converge upgrade the demo to real completions.

Provenance

Built by the agent-network Package Skill, installed with npx skills add and pinned in skills-lock.json. Disposable by design: no backups; recovery is a guarded delete plus create, which mints a fresh endpoint hostname.
